# Personal-Reflections-on-Life

## 关于个人自控
1、当你犯懒时，记得是你内心觉得这件事儿很难，你自己肯定有没有想明白的地方，可以问一下有经验的人或者ai 该怎么做 迈出第一步，后面所有的事儿就顺理成章

## 关于人生未来
1、要有清晰的规划或者对自己的将来有认知，知道将来日子会怎样过，不管好坏要敢于说出来，不要过一天是一天，要勇于承担面对后续的日子，
或许你很迷茫，看不到将来，不知道自己将来会过的怎样，拥有怎样的人生，但是就算再烂，那也是一种生活方式，说出来，让自己有清晰的认识很重要。

## 关于人际关系
1、当某个人关于和你的合作有犹豫时，可能的原因：
  1）处于利益考虑期
  2）自己也没想明白，如果你想明白了，可以给予答案，或者你想促成合作，可以引导
2、当商量一件事儿的时候，给出你自己视角切实可行的计划，精确到每一步可执行的步骤，给到别人，然后看他同不同意，后续再商量，很重要的一点是，一定要有自己的计划

## 关于问题思考
1、现在ai很方便，当遇见问题时，可以和ai一块推演，思考问题会全面很多

## 关于资源的运用
1、遇事先考虑可用资源，你周边的人 也可以是你可使用的资源
